# SwitchLAN Studio Core 1.4.5 — Windows 实机 UI/UX 优化（Beta）

## 范围与原则

基于 Core 1.4.4 完整工程小步迭代。保持 C# .NET 8 WinForms + WebView2 + PowerShell 5.1 技术架构；**未修改任何 C#、PowerShell、启动 .cmd 或 .csproj 文件**。此次改动集中在 `js/app.js`、`assets/style.css`、`index.html`，并新增浏览器验收脚本 `tests/browser-ux145.py`。

## 已实现

1. **窗口 App Shell**：桌面宽度 >820px 时，固定侧边栏与顶部状态栏；主内容区域独立滚动。管理页中的左右面板固定在可用工作区高度，各自滚动；统一轻量滚动条。窄视口沿用纵向页面布局。
2. **共享管理**：移除页面级重复“刷新 Windows”按钮（顶部刷新仍保留）；网络共享地址区域增加主机名 UNC 和所选网卡 IPv4 UNC 两种复制方式，以及**不包含密码**的文字连接说明。IPv4 地址仅是当前所选本机网卡，并不保证远端能够路由/认证访问。
3. **用户管理**：删除重复身份摘要；将账号资料整理为紧凑网格；所属用户组默认展开；列表启用状态使用可访问性标记圆点；不显示没有上下文意义的 `01` 标识。
4. **局域网设备联动**：发现结果的设备卡片新增“加入雷达”和“检测游戏”，携带设备的真实扫描 IP。运行中的雷达禁止擅自变更监控目标。
5. **游戏发现**：默认扫描范围收进高级展开，保留原有 `/24` 扫描实现和输入范围；提示当前网卡的实际前缀（仅作说明，**不代表程序已经扩展为全 CIDR 扫描**）。空结果可直接开始发现。
6. **网络雷达**：IPv4 和可选端口并列，端口初始留空（表示仅 Ping）；增加 ICMP / MC 25565 / SMB 445 快捷选项。未收到采样时，使用清晰网格与提示，避免过度模糊。收到真实网络采样时，对满足阈值且间隔足够的 RTT 尖峰写入内存状态变化列表，避免在短时间内重复提示。阈值为 RTT ≥ max(100ms, 前值×2.5)，且增幅 ≥50ms；这只是监测端 RTT 变化，不是 Wi-Fi、游戏服务器或链路故障归因。
7. **权限分析**：在规则完整读取、所选账户组信息可用但没有可见匹配 ACE 时提示“NTFS 排查线索”。绝不显示“最终无权访问”或自动添加 ACE。
8. **视觉细节**：游戏分类选中态更明显，减少重复背景与提示区的噪声，保持原有 Liquid Glass 风格和文字清晰度。

## 有意不实现的建议及原因

- 不提供包含明文密码、调用 `cmdkey /pass:` 或 `net use * /delete /y` 的批处理脚本：会泄露凭据或误断开用户已有盘符映射。
- 不允许仅凭客户端浏览到的 ACL 列表做“最终 SMB∩NTFS 有效权限”判断或一键补齐，复杂 Windows 访问检查必须由受信的系统层并结合实际令牌完成。
- 不自动更改 `AllowInsecureGuestAuth`、SMB 签名、整个防火墙或网络配置文件，不通过隐式修改注册表隐藏账户。
- 不自动发布 `.minecraft/mods` 目录为 HTTP/SMB 共享，也不将 Java 随机端口无确认地重映射到 25565。
- 不自动扩大现有 `/24` 扫描到 `/16`：跨网络可使用手动目标地址验证，后续须重新设计 CIDR 扫描策略与上限。
- 不替换 WinForms 系统标题栏为无边框窗口：需先进行原生拖动、缩放、DPI、UAC、快捷键和可访问性验证。

## Windows 11 实机验收建议

1. 保留 Core 1.4.4 的独立备份，将新 ZIP 完整解压到新目录；运行 `Check-SwitchLAN.cmd`，再运行 `Start-SwitchLAN.cmd`。
2. 在文件共享和用户管理页检查：最大化、缩小、滚动到底部时顶部标题栏不裁切内容，详情列表滚动时输入框/按钮仍可操作。
3. 选中已有共享，分别复制 `\\主机名\共享名`、`\\本机IPv4\共享名`，确认地址准确且不暴露密码。
4. 先用可信实验网段发现一台设备，从设备卡片进入雷达/游戏，确认 IP 已自动带入。
5. 将真实监测目标加入雷达，检查 1/2/5 分钟窗口及异常状态；不要用不可达主机的 ICMP 超时作为“设备掉线”的直接证据。
6. 在 100%/125%/150% DPI、1080p、小窗口和深色模式下检查排版。若发现异常，将截图与程序诊断输出发送回来。

## 未验证

当前环境不是 Windows 11，没有 .NET GUI 编译和 Windows WebView2 实际运行环境；未验证 UAC 提权、用户/NTFS/SMB 写入、真实网络扫描、Windows DPI、显卡驱动下的折射性能。
